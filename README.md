# 📚 Sistema de Livraria em Java

Projeto desenvolvido em Java com o objetivo de praticar Programação Orientada a Objetos (POO), tratamento de exceções e organização de código.

---

## 🚀 Funcionalidades

- 📖 Cadastro de livros
- 👤 Cadastro de usuários
- 🔄 Empréstimo de livros
- ⚠️ Tratamento de exceções personalizadas:
  - Livro não encontrado
  - Livro indisponível
  - Multa pendente

---

## 🛠️ Tecnologias utilizadas

- Java
- Maven

---

## 📂 Estrutura do Projeto

src/main/java/com/goias
- Controlador.java
- Livro.java
- Usuario.java
- Main.java
- Exceptions personalizadas

---

## 💡 Aprendizados

Neste projeto, pratiquei:

- Programação Orientada a Objetos (POO)
- Criação de exceções personalizadas
- Organização de código em pacotes
- Lógica de negócio em sistemas reais
